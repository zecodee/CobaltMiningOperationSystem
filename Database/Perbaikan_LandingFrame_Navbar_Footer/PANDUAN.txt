PERBAIKAN LANDINGFRAME - NAVBAR TETAP TERLIHAT, FOOTER DI AKHIR HALAMAN

File pengganti: LandingFrame.java dan LandingFrame.form.

Perubahan:
1. Navbar pnlTopBar sekarang menjadi komponen langsung JFrame (di atas scrollMain), sehingga tidak ikut tergulir.
2. JScrollPane hanya memuat konten pnlPage mulai dari Hero sampai Footer.
3. Menghapus ruang kosong 122px di bawah footer dan mengatur ruang fleksibel sebelum footer.
4. Warna, teks, gambar, menu, login, ukuran runtime 1280x800, dan animasi scroll dipertahankan.
5. Semua susunan komponen tersimpan dalam file .form dan blok initComponents yang dihasilkan GUI Builder.

Pemasangan: Ganti kedua file pada package view, tutup tab LandingFrame di NetBeans, buka kembali tab Design, lalu Clean and Build.

Desain NetBeans tetap dibuat memanjang (size 1280x3508) untuk memudahkan mengedit seluruh section. Saat Run, konstruktor mengatur jendela ke 1280x800.

Catatan: Validasi dilakukan secara struktural. Belum diuji langsung pada NetBeans/macOS.
